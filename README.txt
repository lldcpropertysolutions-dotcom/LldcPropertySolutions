FREE PUBLISHING WITH GITHUB PAGES:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository, for example: lldc-property-solutions
3. Upload index.html to the repository.
4. Open Settings > Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select the main branch and the / (root) folder, then Save.
7. GitHub will provide your free website address.
